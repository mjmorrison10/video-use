House style: 9:16 1080×1920 30fps · Big Shoulders Bold ALL-CAPS · yellow power words · burned-in hook · **YuNet face-tracked** cover crop (blur-contain for wide data graphics) · voice-forward ~−13 LUFS · one distinct instrumental per clip.

**Selection:** the client supplied two hook sets — Set A (chosen on historical performance data) and Set B (AI-generated). Per instruction, the agent **prioritized Set A**; all four picks are Set A. Set B's "3 billion heartbeats" math was folded in only where it strengthened a Set A clip.

## Clip 1 — "You Only Get So Many Beats"  · 16.2s · `interstellar.mp3`  *(Set A #7)*
- **Hook:** `YOU ONLY GET SO MANY BEATS`
- **Point:** The proverb that you're born with a fixed number of heartbeats — beat faster, die sooner — and nature backs it up.
- Structure: Hook (you only have so many heartbeats) → Point (beat fast → run out → die sooner) → Reinforce (whales: low heart rate, live far longer than humans) → button (a mouse burns ~1 billion beats in its short life). Animal comparison table shown in full via blur-contain. Fixed a mis-transcription that had inverted the meaning ("cannot → can die sooner").

## Clip 2 — "How I Got to 35 BPM"  · 18.1s · `royalty.mp3`  *(Set A #5)*
- **Hook:** `HOW I GOT TO 35 BPM`
- **Point:** Zone-2 cardio is the specific lever that drops resting heart rate to ~35.
- Structure: Hook (my RHR is 35–39 — elite even among endurance athletes) → Point (I introduce zone-2 cardio) → Point (more cardio → RHR drops to 35) → Reinforce (less cardio → back up to 39–42).

## Clip 3 — "20,000 Steps a Day"  · 15.9s · `night_drive.mp3`  *(Set A #6)*
- **Hook:** `20,000 STEPS A DAY`
- **Point:** The base wasn't the gym — it was walking 15–20k steps a day for years.
- Structure: Hook (before any structured cardio my RHR was already great) → Point (the reason was walking — 15–20k steps every day for years) → Reinforce (higher daily step count → higher HRV across all ages, up to 20k steps).

## Clip 4 — "80 Years vs 114 Years"  · 16.7s · `dark_knight.mp3`  *(Set A #4)*
- **Hook:** `80 YEARS VS 114 YEARS`
- **Point:** A lower resting heart rate across all the hours you're at rest more than makes up for the gym-hour spike — exercise buys you decades of "beat budget."
- Structure: Hook (an 80-year lifespan is ~3 billion heartbeats) → Point (your lower resting heart rate makes up for the exercise spike) → Reinforce (3 billion beats reached in 80 years without exercise vs 114 years with — the difference is massive).
